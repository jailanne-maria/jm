# Portfólio Jailanne Maria

Site de portfólio de **Jailanne Maria** — Vibe Coder & Designer Multidisciplinar.

🔗 **Site:** https://jailanne-maria.github.io/jm/

## Sobre

Site de uma página construído para apresentar meu trabalho como vibe coder e designer: quem eu sou, minhas habilidades, projetos e formas de contato. Todo o visual foi feito para unir a identidade de **floresta** com a de **tecnologia**.

## Seções

- **Hero** — nome, cargo e chamada principal
- **Sobre mim** — perfil multidisciplinar
- **Habilidades** — design, código e IA/vibe coding
- **Projetos** — trabalhos reais (jogo, bot, app, projeto de impacto)
- **Contato** — email, GitHub e localização

## Tecnologias

- HTML5
- CSS3 (variáveis, grid, design responsivo)
- SVG (logo própria)

## Como rodar

Basta abrir o `index.html` no navegador, ou acessar a versão publicada no GitHub Pages.

## Logo

A logo (árvore + circuito) foi desenhada em SVG, usando o gradiente roxo → rosa do site. Representa a união entre floresta e tecnologia.

## Como publicar

Publicado via **GitHub Pages** (branch `main`, pasta raiz). Qualquer push em `main` atualiza o site automaticamente.
